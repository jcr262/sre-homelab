# SRE Lab

Self-hosted kubernetes lab for hand-on SRE pracitce.

## Stack

- Mutipass (KVM) - 3 Ubuntu 24.04 VMs
- k3s - 1 server, 2 agents
- Ubuntu 24.04 host

## Goals

- Operate a multi-node cluster: node failures, storage, networking
- GitOps with ArgoCD
- Observability: Prometheus, Grafana, ELK
- Infrastructure as code: Terraform on Azure and AWS
